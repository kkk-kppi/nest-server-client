# ADR-0003: 动态路由与 RBAC 权限模型

## 状态

已采纳

## 背景

需要按用户角色动态展示可访问页面，未授权用户不应看到路由。

## 决策

- 静态路由仅注册公开页面（home、403、404）
- 登录后按角色动态注入 `/workspace`、`/admin` 路由
- 路由守卫 `beforeEach` 执行 `canAccess(roles, permissions, meta)` 校验
- 角色 OR 逻辑 + 权限 AND 逻辑

## 后果

- 直接访问动态路由 URL 需要 catch-all 重新解析
- 未登录用户看不到 404（被重定向到 home）
- 角色变更需刷新页面重新注入路由
