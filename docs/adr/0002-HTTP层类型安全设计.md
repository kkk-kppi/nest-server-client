# ADR-0002: HTTP 层类型安全设计

## 状态

已采纳

## 背景

需要在编译期保证 API 请求/响应的类型正确性，减少运行时类型错误。

## 决策

- 使用 `defineGetEndpoint/definePostEndpoint` 声明端点，携带 phantom type
- `InferEndpointRequest/InferEndpointResponse` 从端点声明推导类型
- `requestEndpoint` 统一分发，自动解包 `ApiResponse.data`
- 请求去重 + 指数退避重试（仅幂等方法）

## 后果

- 新增 API 必须先声明 endpoint 再调用
- 类型安全在编译期保证，无运行时开销
- Mock handler 可复用同一类型定义
