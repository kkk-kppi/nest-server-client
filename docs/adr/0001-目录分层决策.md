# ADR-0001: 目录分层决策

## 状态

已采纳

## 背景

项目需要一个清晰的目录结构来分离基础设施、业务逻辑和共享代码。

## 决策

采用四层目录结构：

- `src/app/` — 组装层（bootstrap、布局、根组件）
- `src/core/` — 基础设施层（HTTP、路由、Store、配置）
- `src/features/` — 业务域模块（auth、admin、workspace）
- `src/shared/` — 跨域共享（composables、原子组件、工具函数）

## 后果

- 新增功能必须落在对应分层目录
- 禁止跨层反向依赖（features → core 可，core → features 不可）
- 路径别名 `@/` 指向 `src/`
