# 业务模块接入指南

## 1. 概述

本文档以「用户管理」为黄金路径，完整演示从业务需求到可测试交付的全流程。遵循此指南可确保新模块自动获得类型安全、权限控制、国际化、Mock 测试和 E2E 覆盖。

### 1.1 全流程一览

```text
① 定义 API 契约 → ② 添加 Mock Handler → ③ 创建页面组件
→ ④ 注册路由 → ⑤ 配置权限 → ⑥ 添加 i18n 资源
→ ⑦ 编写 Vitest → ⑧ 编写 Playwright E2E
```

### 1.2 目录约定

新模块统一放在 `src/features/<module>/` 下，遵循以下结构：

```text
src/features/<module>/
├── api.ts              # Endpoint 声明与请求函数
├── api.test.ts         # API 契约测试（可选，复杂模块推荐）
├── routes.ts           # 路由 manifest
├── store/              # Pinia store（按需）
├── views/              # 页面组件
│   ├── XxxView.vue
│   └── XxxView.test.ts
└── components/         # 模块内私有组件（按需）
```

## 2. 定义 API 契约

### 2.1 声明 Endpoint

在 `src/features/<module>/api.ts` 中使用 `defineGetEndpoint`、`definePostEndpoint` 等工厂函数声明端点。每个端点携带 phantom type，编译期保证请求/响应类型正确。

```ts
// src/features/example/api.ts
import {
  defineGetEndpoint,
  definePostEndpoint,
  definePutEndpoint,
  defineDeleteEndpoint,
  requestEndpoint,
} from '@/core/http'
import type { PageResult } from '@/core/http'

// ---------- 数据模型 ----------

export interface ExampleItem {
  id: string
  name: string
  status: '0' | '1'
  createdAt: string
}

// ---------- Endpoint 声明 ----------

export const getExamplePageEndpoint = defineGetEndpoint<
  '/api/example/items',
  PageResult<ExampleItem>,
  { name?: string; status?: string; page?: number; pageSize?: number }
>('/api/example/items')

export const createExampleEndpoint = definePostEndpoint<
  '/api/example/items',
  ExampleItem,
  Pick<ExampleItem, 'name' | 'status'>
>('/api/example/items')

export const updateExampleEndpoint = definePutEndpoint<
  '/api/example/items/:id',
  ExampleItem,
  Partial<Pick<ExampleItem, 'name' | 'status'>>
>('/api/example/items/:id')

export const deleteExampleEndpoint = defineDeleteEndpoint<'/api/example/items/:id', void>(
  '/api/example/items/:id',
)

// ---------- 请求函数 ----------

export type ExamplePageData = InferEndpointResponse<typeof getExamplePageEndpoint>
export type ExamplePageQuery = InferEndpointRequest<typeof getExamplePageEndpoint>

export async function getExamplePage(query: ExamplePageQuery) {
  return requestEndpoint(getExamplePageEndpoint, { query })
}

export async function createExample(body: InferEndpointRequest<typeof createExampleEndpoint>) {
  return requestEndpoint(createExampleEndpoint, { body })
}

export async function updateExample(
  id: string,
  body: InferEndpointRequest<typeof updateExampleEndpoint>,
) {
  return requestEndpoint(updateExampleEndpoint, { pathParams: { id }, body })
}

export async function deleteExample(id: string) {
  return requestEndpoint(deleteExampleEndpoint, { pathParams: { id } })
}
```

### 2.2 关键规则

- **path 参数**使用 `:name` 语法，由 `requestEndpoint` 自动 URL 编码替换。
- **GET/DELETE** 使用 `query`，**POST/PUT/PATCH** 使用 `body`。
- `:id` 等 path 参数在请求发出前若未解析会抛错，不会发出含 `/:id` 的原始 URL。
- 响应类型从 endpoint phantom type 自动推导，无需手写泛型。

## 3. 添加 Mock Handler

在 `src/mocks/handlers.ts` 中为新 endpoint 添加 MSW handler。

### 3.1 Handler 模式

```ts
import {
  getExamplePageEndpoint,
  createExampleEndpoint,
  updateExampleEndpoint,
  deleteExampleEndpoint,
} from '@/features/example/api'

// 内存数据
const exampleItems = [{ id: '1', name: '示例项', status: '0' as const, createdAt: '2026-01-01' }]

// 分页查询
http.get('/api/example/items', ({ request }) => {
  const url = new URL(request.url)
  const page = Number(url.searchParams.get('page') ?? 1)
  const pageSize = Number(url.searchParams.get('pageSize') ?? 10)
  const start = (page - 1) * pageSize
  return HttpResponse.json({
    code: 200,
    message: 'ok',
    data: { items: exampleItems.slice(start, start + pageSize), total: exampleItems.length },
  })
})

// 新增
http.post('/api/example/items', async ({ request }) => {
  const body = await request.json()
  const newItem = {
    id: String(exampleItems.length + 1),
    ...body,
    createdAt: new Date().toISOString(),
  }
  exampleItems.push(newItem)
  return HttpResponse.json({ code: 200, message: 'ok', data: newItem })
})

// 修改
http.put('/api/example/items/:id', async ({ params, request }) => {
  const body = await request.json()
  const item = exampleItems.find((i) => i.id === params.id)
  if (!item) return HttpResponse.json({ code: 404, message: 'not found' }, { status: 404 })
  Object.assign(item, body)
  return HttpResponse.json({ code: 200, message: 'ok', data: item })
})

// 删除
http.delete('/api/example/items/:id', ({ params }) => {
  const idx = exampleItems.findIndex((i) => i.id === params.id)
  if (idx === -1) return HttpResponse.json({ code: 404, message: 'not found' }, { status: 404 })
  exampleItems.splice(idx, 1)
  return HttpResponse.json({ code: 200, message: 'ok', data: null })
})
```

### 3.2 Mock 场景覆盖

推荐为关键接口补充以下场景：

| 场景         | 实现方式                                  |
| ------------ | ----------------------------------------- |
| 401 未授权   | 检查 `Authorization` header，缺失返回 401 |
| 403 无权限   | 检查角色/权限，返回 403                   |
| 422 校验失败 | 检查必填字段，返回字段级错误              |
| 500 服务异常 | 直接返回 500                              |

## 4. 创建页面组件

使用 `ProTable` + `ProForm` + `useMutation` + `usePermission` 组合构建 CRUD 页面。

### 4.1 页面模板

```vue
<!-- src/features/example/views/ExampleView.vue -->
<script setup lang="ts">
import { ref, h } from 'vue'
import { useI18n } from 'vue-i18n'
import { NButton, NSpace, NTag, NPopconfirm, NModal } from 'naive-ui'
import { ProTable, ProForm } from '@/shared/components/pro'
import { useMutation } from '@/shared/composables/useMutation'
import { usePermission } from '@/features/auth'
import { getExamplePage, createExample, updateExample, deleteExample } from '../api'
import type { ExampleItem } from '../api'

const { t } = useI18n()
const { canCreateExample, canUpdateExample, canDeleteExample } = usePermission()

const tableRef = ref()
const showModal = ref(false)
const editingItem = ref<ExampleItem | null>(null)
const formValue = ref({ name: '', status: '0' as '0' | '1' })

const columns = [
  { title: '名称', key: 'name' },
  {
    title: '状态',
    key: 'status',
    render: (row: ExampleItem) =>
      h(NTag, { type: row.status === '0' ? 'success' : 'warning' }, () =>
        row.status === '0' ? '启用' : '停用',
      ),
  },
  {
    title: '操作',
    key: 'action',
    render: (row: ExampleItem) =>
      h(NSpace, { size: 'small' }, () => [
        canUpdateExample.value
          ? h(NButton, { size: 'small', onClick: () => handleEdit(row) }, () => '编辑')
          : null,
        canDeleteExample.value
          ? h(
              NPopconfirm,
              { onPositiveClick: () => deleteMutate.mutate(row.id) },
              {
                trigger: () => h(NButton, { size: 'small', type: 'error' }, () => '删除'),
                default: () => '确认删除？',
              },
            )
          : null,
      ]),
  },
]

const searchFields = [
  { name: 'name', label: '名称', type: 'input' as const },
  {
    name: 'status',
    label: '状态',
    type: 'select' as const,
    options: [
      { label: '启用', value: '0' },
      { label: '停用', value: '1' },
    ],
  },
]

const formFields = [
  { name: 'name', label: '名称', type: 'input' as const, required: true },
  {
    name: 'status',
    label: '状态',
    type: 'select' as const,
    options: [
      { label: '启用', value: '0' },
      { label: '停用', value: '1' },
    ],
  },
]

const createMutate = useMutation({
  mutationFn: createExample,
  onSuccess: () => {
    showModal.value = false
    tableRef.value?.refresh()
  },
})

const updateMutate = useMutation({
  mutationFn: (data: { id: string; body: Parameters<typeof updateExample>[1] }) =>
    updateExample(data.id, data.body),
  onSuccess: () => {
    showModal.value = false
    tableRef.value?.refresh()
  },
})

const deleteMutate = useMutation({
  mutationFn: deleteExample,
  onSuccess: () => tableRef.value?.refresh(),
})

async function request(params: Record<string, unknown>) {
  const res = await getExamplePage(params as never)
  return { items: res.items, total: res.total }
}

function handleAdd() {
  editingItem.value = null
  formValue.value = { name: '', status: '0' }
  showModal.value = true
}

function handleEdit(row: ExampleItem) {
  editingItem.value = row
  formValue.value = { name: row.name, status: row.status }
  showModal.value = true
}

async function handleSubmit(validatedValue: Record<string, unknown>) {
  if (editingItem.value) {
    await updateMutate.mutate({ id: editingItem.value.id, body: validatedValue as never })
  } else {
    await createMutate.mutate(validatedValue as never)
  }
}
</script>

<template>
  <ProTable
    ref="tableRef"
    :columns="columns"
    :request="request"
    :search-fields="searchFields"
    row-key="id"
  >
    <template #toolbar>
      <NButton v-if="canCreateExample" type="primary" @click="handleAdd">
        {{ t('common.add') }}
      </NButton>
    </template>
  </ProTable>

  <NModal
    v-model:show="showModal"
    preset="card"
    :title="editingItem ? '编辑' : '新增'"
    style="width: 480px"
  >
    <ProForm
      :fields="formFields"
      :model-value="formValue"
      @submit="handleSubmit"
      @cancel="showModal = false"
    />
  </NModal>
</template>
```

### 4.2 关键模式

- **ProTable** 接收 `request` 函数，自动管理分页、搜索、重置和竞态。
- **ProForm** 接收 `fields` 定义，自动校验 `required` 字段，暴露 `validate/reset`。
- **useMutation** 提供 `idle/loading/success/error` 状态和重复提交保护。
- **usePermission** 提供响应式权限判断，控制按钮显示/隐藏。

## 5. 注册路由

### 5.1 创建路由 Manifest

在 `src/features/<module>/routes.ts` 中导出路由数组：

```ts
// src/features/example/routes.ts
import type { RouteRecordRaw } from 'vue-router'

export const exampleRoutes: RouteRecordRaw[] = [
  {
    path: '/example',
    component: () => import('@/app/layouts/AdminLayout.vue'),
    meta: {
      title: '示例管理',
      icon: 'CubeOutline',
      order: 50,
      requiresAuth: true,
      roles: ['admin'],
      permissions: ['example:read'],
    },
    children: [
      {
        path: '',
        name: 'example',
        component: () => import('./views/ExampleView.vue'),
        meta: {
          title: '示例列表',
          icon: 'ListOutline',
          requiresAuth: true,
          roles: ['admin'],
          permissions: ['example:read'],
        },
      },
    ],
  },
]
```

### 5.2 注册到动态路由

在 `src/features/auth/dynamic-routes.ts` 中将新路由加入角色映射：

```ts
import { exampleRoutes } from '@/features/example/routes'

const ROLE_ROUTE_MAP: Record<UserRole, RouteRecordRaw[]> = {
  admin: [...workspaceRoutes, ...adminRoutes, ...systemRoutes, ...exampleRoutes],
  editor: [...workspaceRoutes],
  viewer: [...workspaceRoutes],
}
```

### 5.3 路由安全

- 未声明 `meta.public` 的路由默认要求认证（fail-closed）。
- `roles` 是任一匹配（OR），`permissions` 是全部匹配（AND）。
- 登出时 `resetDynamicRoutes()` 自动卸载已安装路由，新身份登录后重新初始化。

## 6. 配置权限

### 6.1 权限命名规范

```text
<module>:<resource>:<action>
```

示例：`example:item:read`、`example:item:create`、`example:item:update`、`example:item:delete`

### 6.2 在 usePermission 中暴露

在 `src/features/auth/usePermission.ts` 中添加新的权限计算属性：

```ts
const canCreateExample = computed(() => hasPermission(['example:item:create']))
const canUpdateExample = computed(() => hasPermission(['example:item:update']))
const canDeleteExample = computed(() => hasPermission(['example:item:delete']))
```

### 6.3 在页面中使用

```ts
const { canCreateExample, canUpdateExample, canDeleteExample } = usePermission()

// 模板中
v-if="canCreateExample"
```

或使用 `AccessControl` 组件：

```vue
<AccessControl :permissions="['example:item:create']">
  <NButton type="primary">新增</NButton>
</AccessControl>
```

```ts
import { describe, it, expect, vi } from 'vitest'
import { mount } from '@vue/test-utils'
import { createTestingPinia } from '@pinia/testing'
import { NConfigProvider, NMessageProvider } from 'naive-ui'
import { createI18n } from 'vue-i18n'
import ExampleView from './ExampleView.vue'
import { useAuthStore } from '@/features/auth/store/useAuthStore'
import zhCN from '@/core/i18n/zh-CN'

const i18n = createI18n({
  legacy: false,
  locale: 'zh-CN',
  messages: { 'zh-CN': zhCN },
})

function createWrapper(permissions: string[] = ['example:item:read', 'example:item:create']) {
  const pinia = createTestingPinia({
    createSpy: vi.fn,
  })
  const authStore = useAuthStore(pinia)
  authStore.roles = ['admin']
  authStore.permissions = permissions

  return mount(ExampleView, {
    global: {
      plugins: [pinia, i18n],
      components: { NConfigProvider, NMessageProvider },
    },
  })
}

describe('ExampleView', () => {
  it('renders without errors', () => {
    const wrapper = createWrapper()
    expect(wrapper.exists()).toBe(true)
  })

  it('shows add button when has create permission', () => {
    const wrapper = createWrapper(['example:item:create'])
    expect(wrapper.find('button').exists()).toBe(true)
  })

  it('hides add button when lacks create permission', () => {
    const wrapper = createWrapper(['example:item:read'])
    const buttons = wrapper.findAll('button')
    const addButton = buttons.find((b) => b.text().includes('新增'))
    expect(addButton).toBeUndefined()
  })
})
```

## 11. 常见问题

### Q: 新模块的 Mock 数据没有生效？

确认 `src/mocks/handlers.ts` 中已导入新 endpoint 并添加 handler，且开发环境 `.env.development` 中 `VITE_ENABLE_MOCK=true`。

### Q: 路由注册后访问 404？

检查 `src/features/auth/dynamic-routes.ts` 中是否将新路由加入了对应角色的映射。

### Q: 权限按钮没有隐藏？

确认 `usePermission.ts` 中已暴露新的权限计算属性，且页面中正确解构使用。

### Q: ProForm 校验不生效？

确认 `fields` 中设置了 `required: true`，且页面调用了 `validate()` 方法后再提交。

### Q: E2E 测试找不到元素？

优先使用可访问角色定位器（`getByRole`、`getByLabel`、`getByText`），避免依赖 CSS 类名。Naive UI 组件的内部结构可能随版本变化。
